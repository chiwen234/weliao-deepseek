微聊 · DeepSeek 联机版

微信 UI 的单人 AI 角色聊天程序 · Python 标准库后端 + 单文件前端

为什么这里不能直接玩

  • 它需要 本机 Python 后端（server.py）来调用 DeepSeek API、读写存档与照片，静态托管无法运行。
  • API Key 只在后端环境变量里，永远不会出现在网页中，所以也不可能在这个静态页面上工作。
  • 若强行把完整前端托管到公网，会连带暴露聊天记录、共同回忆与她本人的照片。

本地运行

  1. 安装 Python 3.10 或更高版本。
  2. 下载仓库源码，或在 Windows 上使用完整本地包。
  3. 在 启动.bat 里填入自己的 DeepSeek API Key。
  4. 双击 启动.bat，浏览器打开 http://127.0.0.1:8787/，黑色窗口保持打开。
